## Restricciones globales

Todas las de la fase 2 (`docs/plans/2026-10-03-fase-2.md` → "Restricciones globales") siguen
vigentes. Además:

- **Las pruebas no tocan la red ni la API.** Nada de `github.com` en `pytest`: los "remotos" son
  repos *bare* locales (`file://`). Telegram, siempre con `post` inyectado.
- **Las pruebas no tocan el vault, `/data/github-abordaje` ni el cerrojo real.** Todo con
  `tmp_path` y con los parámetros `raiz_*` / `--cerrojo` que define cada tarea.
- **Sin dependencias nuevas.** `git` por `subprocess`; HTTP con `urllib.request`; el frontmatter, a mano.
- **El código del enjambre escribe en el vault solo a través de `enjambre/nota.py`** y solo
  dentro de `Clippings/repo-articles/`. Tú, como sesión, sigues sin tocar el vault (las pruebas
  usan `tmp_path`). Contrato del vault: `99-meta/contrato-proyecto.md` §5, excepción `Clippings/`.
- **No instales nada en el sistema.** Las unidades systemd se dejan en `systemd/`; las instala Josem (Tarea 24).
- `.env` con secretos: **nunca** lo creas, lo lees en pruebas ni lo commiteas. Lo crea Josem (D34).
- Commits pequeños, `git add` de ficheros concretos, mensaje terminado en
  `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Foco de revisión

Lo que más probablemente muerda y el revisor va a mirar en el código, no solo en las pruebas:

1. **`git` nunca pide credenciales.** Un repo privado o inexistente en GitHub, con terminal, pide
   usuario y contraseña y deja colgada la noche. Todo `git` va con `GIT_TERMINAL_PROMPT=0`,
   `GIT_ASKPASS=` vacío, `stdin=DEVNULL` y timeout. → Tarea 18.
2. **Inyección por la URL.** La URL acaba en un argv de `git`: lista de argumentos (nunca
   `shell=True`), `--` antes de URL y ruta, y el nombre validado (`[A-Za-z0-9_.-]`, ni `.` ni `..`,
   sin empezar por `-`). → Tarea 18.
3. **`reset --hard` + `clean -fdx` solo dentro de `raiz_copias`.** Una fuente local (D26) nunca
   se modifica; antes de limpiar, comprueba que la ruta resuelta está dentro de `raiz_copias`. → Tarea 18.
4. **Coste de una continuación.** `run_fin.coste_total_usd` de `reanudar` incluye lo gastado antes
   (D24). Para el techo de la noche (D30) cuenta solo lo de esta lectura. → Tareas 22 y 23.
5. **El cerrojo cubre el run entero**, también la clonación, y lo toma el proceso que ejecuta el
   run, no la pantalla (D31). → Tareas 19, 22 y 25.

```python
# tests/gitutil.py
import subprocess
from pathlib import Path


def git(*args: str, cwd: Path | None = None) -> str:
    r = subprocess.run(
        ["git", "-c", "user.name=t", "-c", "user.email=t@t", "-c", "init.defaultBranch=trunk", *args],
        cwd=cwd, check=True, capture_output=True, text=True,
    )
    return r.stdout.strip()


def repo_con_commit(ruta: Path, fichero: str = "a.py", texto: str = "x = 1\n") -> Path:
    ruta.mkdir(parents=True, exist_ok=True)
    if not (ruta / ".git").exists():
        git("init", cwd=ruta)
    (ruta / fichero).write_text(texto)
    git("add", fichero, cwd=ruta)
    git("commit", "-m", f"{fichero}", cwd=ruta)
    return ruta


def rev(ruta: Path) -> str:
    return git("rev-parse", "HEAD", cwd=ruta)
```

### Tarea 18: `enjambre/fuente.py` (D26, D27)

```python
RAIZ_COPIAS = Path("/data/github-abordaje")

class FuenteInvalida(ValueError): ...
class CopiaAjena(RuntimeError): ...   # el directorio existe y no es una copia de esta URL
class GitFallo(RuntimeError): ...     # clonar o actualizar falló (privado, inexistente, red, timeout)

@dataclass(frozen=True)
class Fuente:
    texto: str        # forma canónica: "https://github.com/<dueño>/<repo>" o ruta absoluta resuelta
    nombre: str       # <repo>, o el nombre del directorio local
    url: str | None   # = texto si es de GitHub; None si es local

def resolver(texto: str, *, raiz_local: Path = Path("/data"), raiz_copias: Path = RAIZ_COPIAS) -> Fuente: ...
def actualizar(f: Fuente, *, raiz_copias: Path = RAIZ_COPIAS, remoto: str | None = None,
               timeout_s: float = 300) -> tuple[Path, str | None]: ...
```

`resolver` es pura (no llama a `git` ni a la red). `actualizar` devuelve `(ruta, commit)`.
`remoto` sustituye a `f.url` como URL de clonado: lo usan las pruebas (`file://`). El `origin`
de una copia existente se compara contra él, sin `.git` ni barra final.

Para una URL: si no hay copia, `git clone --depth 1 -- <remoto> <ruta>`, y si el clon falla, no
queda nada a medias. Si la hay: `origin` igual o `CopiaAjena`; después
`fetch --depth 1 origin`, `remote set-head origin --auto`, `reset --hard origin/HEAD` y
`clean -fdx`. Para una fuente local: no se toca nada, y `commit` es `rev-parse HEAD`, o `None`
si no es un repo git.

### Tarea 19: `enjambre/cerrojo.py` (D31) y el cerrojo en `orquestar.main`

```python
RUTA = <raíz del repo> / "cerrojo.lock"

class Ocupado(RuntimeError): ...

@contextmanager
def tomar(ruta: Path = RUTA): ...   # flock LOCK_EX | LOCK_NB; si no puede, Ocupado
def ocupado(ruta: Path = RUTA) -> bool: ...   # prueba a tomarlo y lo suelta
```

`orquestar.main` acepta `--cerrojo <ruta>` (por defecto `cerrojo.RUTA`) y ejecuta todo el run,
también `--reanudar`, dentro de `tomar`. Si está ocupado, escribe en stderr
`hay otro run en marcha` y devuelve **3**. Las funciones `orquestar()` y `reanudar()` no toman el
cerrojo: es cosa de quien ejecuta (CLI o cola), y así las pruebas existentes no cambian.

```python
# tests/test_cerrojo.py
import subprocess
import sys

import pytest

from enjambre.cerrojo import Ocupado, ocupado, tomar

RETENER = (
    "import fcntl, sys, time\n"
    "f = open(sys.argv[1], 'a')\n"
    "fcntl.flock(f, fcntl.LOCK_EX)\n"
    "print('ok', flush=True)\n"
    "time.sleep(30)\n"
)


@pytest.fixture
def retenido(tmp_path):
    ruta = tmp_path / "c.lock"
    p = subprocess.Popen([sys.executable, "-c", RETENER, str(ruta)], stdout=subprocess.PIPE, text=True)
    assert p.stdout.readline().strip() == "ok"
    yield ruta
    p.kill()
    p.wait()


def test_otro_proceso_lo_tiene(retenido):
    assert ocupado(retenido)
    with pytest.raises(Ocupado):
        with tomar(retenido):
            pass


def test_muere_el_proceso_y_queda_libre(tmp_path):
    ruta = tmp_path / "c.lock"
    p = subprocess.Popen([sys.executable, "-c", RETENER, str(ruta)], stdout=subprocess.PIPE, text=True)
    assert p.stdout.readline().strip() == "ok"
    p.kill()
    p.wait()
    assert not ocupado(ruta)


def test_tomar_y_soltar(tmp_path):
    ruta = tmp_path / "c.lock"
    with tomar(ruta):
        assert ocupado(ruta)
    assert not ocupado(ruta)


def test_orquestar_main_respeta_el_cerrojo(retenido, tmp_path, capsys):
    from enjambre.orquestar import main
    repo = tmp_path / "agora"
    repo.mkdir()
    codigo = main(["--repo", str(repo), "--falso", "--salidas", str(tmp_path / "s"), "--cerrojo", str(retenido)])
    assert codigo == 3
    assert "hay otro run en marcha" in capsys.readouterr().err
    assert not (tmp_path / "s").exists()
```

El frontmatter se escribe como `clave: <valor en JSON>`, una línea por clave y en este orden:
`fuente, commit, leido, run, coste_usd, veredicto, generado_por`. Un string JSON es YAML válido y
Obsidian lo lee como propiedad. `leer_frontmatter` solo tiene que entender lo que escribe
`escribir`. La escritura es atómica: un temporal en la misma carpeta y `os.replace`.

### Tarea 21: `enjambre/aviso.py` (D32, D34)

### Tarea 22: `enjambre/leer.py`

```python
async def leer(f: Fuente, *, salidas: Path, lanzar: Lanzar, raiz_copias: Path = RAIZ_COPIAS,
               raiz_notas: Path = RAIZ_NOTAS, tope_usd: float = 5.0, max_vueltas: int = 2,
               run: str | None = None, falso: bool = False, reanudar: Path | None = None,
               saltar_si_igual: bool = False, remoto: str | None = None,
               ahora=datetime.now) -> Lectura: ...

def ultimo_parado(salidas: Path, fuente: str) -> Path | None: ...
def main(argv: list[str] | None = None) -> int: ...
```

`leer`, en orden:

1. `actualizar(f)`.
2. Con `saltar_si_igual`: si la nota existe con esta `fuente` y este `commit`, no se lanza nada y se
   devuelve `motivo="sin_cambios"`, coste 0.
3. Con `reanudar`: si el `commit` del `run_inicio` de ese run es el de ahora, se continúa (D24).
   Si no, se lanza un run nuevo: el código ha cambiado. Sin `reanudar`, siempre es un run nuevo,
   con `fuente=f.texto` y `commit`.
4. Si el motivo es final (D28), se escribe la nota. Con `falso=True`, la nota va a
   `<salida>/nota.md` y **nunca** a `raiz_notas`: la demo no ensucia el vault.

`leer` no toma el cerrojo ni avisa: eso es de `main` y de la cola.

`ultimo_parado` busca entre los runs de `salidas/*/*/eventos.jsonl` con `run_inicio.fuente == fuente`
el más reciente por el `t` de `run_inicio`. Lo devuelve si su última línea es un `run_fin` con un
motivo no final. En cualquier otro caso devuelve `None`: aprobado, `tope_vueltas`, sin `run_fin`
(muerto o en marcha) o sin runs.

CLI: `python -m enjambre.leer <fuente> [--tope-usd] [--max-vueltas] [--run] [--salidas] [--falso] [--cerrojo] [--sin-aviso]`
o `python -m enjambre.leer --reanudar <salida> [--tope-usd] ...`. Con `--reanudar` sin fuente, la
fuente sale del `run_inicio`. Si allí es `None` (un run anterior a esta fase), se continúa como
hoy: sin actualizar, sin nota y sin aviso. Todo dentro de `tomar(--cerrojo)`. Avisa con
`texto_run`, salvo con `--sin-aviso` o `--falso`; con `--falso`, el texto se imprime. Códigos de
salida: 0 si hay nota, 1 si el run se paró, 2 si la fuente es inválida, la copia ajena, git falla o
la nota es ajena (con el mensaje en stderr), 3 si el cerrojo está ocupado, 130 si se interrumpe.

## H3 — La cola y la noche

### Tarea 23: `enjambre/cola.py` (D29, D30)

```python
RAIZ_COLA = <raíz del repo> / "cola"     # pendientes/, hechas/, fallidas/

def encolar(texto: str, *, raiz_cola: Path = RAIZ_COLA, ahora=datetime.now, **resolver_kw) -> tuple[Path, bool]: ...
def pendientes(raiz_cola: Path = RAIZ_COLA) -> list[dict]: ...   # y fallidas(raiz_cola), igual
async def noche(*, raiz_cola: Path, leer_fn, techo_usd: float = 10.0, tope_run_usd: float = 5.0,
                minimo_usd: float = 1.0, max_intentos: int = 3, ahora=datetime.now) -> dict: ...
def main(argv: list[str] | None = None) -> int: ...
```

Cada petición es `pendientes/<AAAAMMDD-HHMMSS>-<nombre>.json` con
`{"fuente", "nombre", "encolado", "intentos", "historial": []}` y se procesa en orden de nombre de
fichero. `encolar` valida con `resolver` (sin git): una fuente inválida es `FuenteInvalida`. Si la
misma fuente ya está pendiente, devuelve `(esa, False)` y no crea nada. Las escrituras son atómicas
(temporal y `os.replace`); los cambios de estado se hacen con `os.replace` entre carpetas.

`leer_fn(fuente_texto, tope_usd) -> Lectura` es async. El `leer_fn` real, que monta `main`, resuelve
la fuente, busca `ultimo_parado` y llama a `leer(..., reanudar=..., saltar_si_igual=True)`. La
cola no sabe nada de commits.

Reglas de `noche`, por petición:

- `disponible = techo − gastado`. Si `disponible < minimo_usd`, para (`parada="techo"`) y lo
  que queda sigue pendiente.
- Llama a `leer_fn(fuente, min(tope_run_usd, disponible))` y suma `coste_usd` a `gastado`.
- Motivo `aprobado`, `tope_vueltas` o `sin_cambios` → `hechas/`.
- Excepción de `leer_fn`: es un problema de ese repo (privado, copia ajena, nota ajena). Se
  apunta en `errores`, se suma un intento y se sigue con la siguiente.
- Cualquier otro motivo suma un intento. Además, si el motivo empieza por `fallo:` o
  `excepcion:`, o es `interrumpido`, **se para la noche** (`parada=<motivo>`): lo más probable es el
  límite de uso de la suscripción, y seguir solo gastaría intentos.
- Con `intentos >= max_intentos`, la petición pasa a `fallidas/`.
- Cada intento añade a `historial` un `{"t", "motivo" | "error", "coste_usd", "run"}`.

Devuelve `{"lecturas", "errores", "gastado_usd", "quedan", "parada"}`, la forma que usa `texto_noche`.

`main` (`python -m enjambre.cola [--falso] [--cerrojo] [--techo-usd]`):

- Si la cola está vacía, sale con 0 **sin avisar**.
- Toma el cerrojo **para toda la noche**. Si está ocupado, avisa "esta noche no: había otro run en
  marcha" y sale con 3.
- Si no, ejecuta `noche` y avisa con `texto_noche`. Con `--falso`, `lanzar` es el falso, las notas
  van a `<salida>/nota.md` y el aviso se imprime: así se prueba la unidad systemd sin gastar.

### Tarea 25: URL, Lanzar ahora / Encolar, la cola en la portada

Servidor (`pantalla.py`):

- `_valida_lanzar`: `repo` puede ser una URL o una ruta y se valida con `fuente.resolver`
  (`raiz_local=raiz_repos`). Devuelve la fuente canónica. El resto (tope ≤ 10, vueltas 0-3,

```python
def clonar(f: Fuente, destino: Path, *, remoto: str | None = None, timeout_s: float = 120) -> str:
    """Clon `--depth 1` en `destino` (que no existe). Sin marca D38: es un temporal. Devuelve el commit."""

# enjambre/peso.py
CODIGO = frozenset({".py", ".js", ".mjs", ".cjs", ".ts", ".tsx", ".jsx", ".go", ".rs", ".java", ".kt",
                    ".rb", ".php", ".c", ".h", ".cpp", ".hpp", ".cs", ".swift", ".sh", ".sql", ".vue",
                    ".svelte", ".css", ".scss", ".html", ".toml", ".yaml", ".yml"})
EXCLUIDOS = frozenset({"node_modules", "vendor", "third_party", "dist", "build", ".venv", "venv",
                       "__pycache__", ".git"})
MAX_FICHERO = 200_000          # bytes; más grande = generado o minificado: cuenta en el total, no como código
# (banda, tokens hasta (exclusivo), usd_min, usd_max) — calibrado con §9.1; L y XL con un solo dato (D40 tentativa)
BANDAS = (("S", 75_000, 1.0, 3.0), ("M", 1_500_000, 3.5, 5.0), ("L", 6_000_000, 5.0, 8.0), ("XL", None, 7.0, 12.0))

@dataclass(frozen=True)
class Peso:
    ficheros: int; bytes: int; ficheros_codigo: int; bytes_codigo: int
    @property
    def tokens(self) -> int: return self.bytes_codigo // 4

@dataclass(frozen=True)
class Estimacion:
    banda: str; usd_min: float; usd_max: float; tope_usd: float
    alerta: Literal["cabe", "justo", "no cabe"]

def pesar(ruta: Path) -> Peso: ...
def estimar(p: Peso, tope_usd: float = 5.0) -> Estimacion: ...
def texto(p: Peso, e: Estimacion) -> str: ...
def pesar_fuente(f: Fuente, *, remoto: str | None = None, tmp: Path | None = None) -> Peso: ...
def como_dict(p: Peso, e: Estimacion) -> dict: ...   # asdict de los dos + "tokens"; es lo que va a run_inicio.peso
```

Reglas:

- `pesar` usa `fuente.ficheros`. Si da `None` (carpeta sin git), recorre el disco. En los dos casos se
  ignora todo fichero que tenga un segmento de ruta en `EXCLUIDOS`, y los symlinks no se siguen.
  Total = todo lo que queda, con su tamaño. Código = extensión en `CODIGO` (en minúsculas),
  `<= MAX_FICHERO` y sin un byte `\0` en los primeros 8 KiB.
- `estimar`: es la primera banda cuyo «hasta» sea mayor que `tokens`. `alerta` vale `cabe` si
  `usd_max <= tope`, `no cabe` si `usd_min > tope` y `justo` en otro caso.
- `texto`: `"<ficheros> ficheros, <tamaño> · código <tamaño> (~<tokens> tokens) · <banda> · <min>-<max> $ · <alerta>"`.
  Miles con punto. El tamaño va en kB enteros si es menor de 1.000.000 bytes y si no en MB con un
  decimal; en los dos casos, base 1000 y coma decimal. Los tokens van como `~132k` (truncado) por
  debajo de un millón, y como `~20,5M` (un decimal) a partir de ahí. Los dólares, sin «,0» sobrante.
  La alerta se escribe `cabe en 5 $`, `justo para 5 $` o `no cabe en 5 $`.
- `pesar_fuente`: una URL se clona con `clonar` en un `TemporaryDirectory(dir=tmp)` que se borra
  siempre. **Nunca toca `RAIZ_COPIAS`.** Una ruta local se pesa en su sitio.
- CLI `python -m enjambre.peso <fuente> [--tope-usd 5]`: imprime `texto` y sale con 0;
  `FuenteInvalida` → 2; `GitFallo` → 1.
- `leer`, en un **run nuevo** (no al continuar ni en `sin_cambios`), hace `pesar(ruta)` y
  `estimar(..., tope_usd)` después de `actualizar`, y pasa `peso=como_dict(...)` a `orquestar`, que lo
  emite en `run_inicio` (campo añadido, §4; `None` si falla). Si `pesar` lanza `OSError` o
  `GitFallo`, se registra un warning y el run sigue con `peso=None`: el peso nunca para una lectura.
- La página: `POST /api/pesar {"repo", "tope_usd"?}` (mismas cabeceras anti-CSRF y misma
  validación de fuente que `/api/encolar`) → `200 {"texto", "peso", "estimacion"}`, `400` si la
  fuente no vale y `502` con `GitFallo`. No toma el cerrojo ni lanza subprocesos.
  `crear_servidor(..., pesar=None)` admite inyectarlo (por defecto `peso.pesar_fuente`). En el
  formulario, un botón **«Pesar»** junto a «Lanzar ahora» y «Encolar» enseña `texto`, en rojo si la

### Tarea 30: sacar de la cola (D42)
